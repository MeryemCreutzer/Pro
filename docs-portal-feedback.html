Case Study

Redesigning the Docs Portal & Feedback System

A documentation portal redesign focused on visual clarity, information architecture, topic structure, and better feedback loops for continuous improvement.

The portal needed more than a visual refresh. It needed a clearer content system.

The project rethought the documentation experience from the homepage and navigation down to topic types, content blocks, feedback forms, and reusable UI patterns.

Client
PcVue
Type
Documentation UX Redesign
Role
UX Engineer & Information Architect
Published
April 23, 2025

Context

The original documentation portal had an outdated interface and a fragmented, overly segmented structure. Related content was scattered, links were missing, and topic organization lacked consistency.

The result was an inflated documentation experience that was difficult to navigate and maintain. A basic feedback option existed, but it gave limited insight into user needs, missing information, or content gaps.

Key Outcomes

  • Rebranded documentation portal with modern UI/UX
  • Macro-level content restructuring and clearer hierarchy
  • Micro-level content refinement through defined topic types
  • Feedback system for ideas, bug reports, and surveys
  • Figma-based UI, icon, and content planning system

Process

01

Audit & Evaluation

I compared the legacy portal against UX writing and content design best practices, then identified weaknesses in hierarchy, visual clarity, and interaction.

02

Content Type Definition

I created reusable topic classifications such as overview, task, and concept, each with distinct goals and layouts.

03

Macro-Level Redesign

I rebuilt the homepage and navigation logic with clearer content blocks, hover interactions, and a more usable table of contents layout.

04

Feedback Integration

I designed Microsoft Forms for bug reports, idea submissions, and usability surveys to support continuous documentation improvement.

My Role

I led the documentation experience revamp: redesigning the visual layout in Figma, reworking the topic architecture, defining content types, and implementing a feedback mechanism with Microsoft Forms.

I also proposed a long-term strategy for evolving documentation at both macro and micro levels.

UI/UX Design

Figma was used to prototype and refine the portal interface, icons, cards, topic styling, and feedback modals. The goal was to create an experience that felt more modern while improving accessibility, brand alignment, and user flow.

Outcome

Although the full visual redesign and micro-level structural refinements have not yet been implemented across all product lines because of organizational constraints, the proposed architecture and design system were successfully applied and validated in the documentation for a new product, EmVue.

The macro-level reorganization already brought clarity and usability improvements, creating a scalable documentation design direction ready to expand when the organization can adopt it fully.

What Changed

  • Clearer topic architecture
  • More intentional homepage structure
  • Reusable content principles
  • Improved feedback collection
  • Design-ready documentation components
